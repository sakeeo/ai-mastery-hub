## Yang bukan aturan mesin

Angka tampilan adalah target kerja, bukan batas dari Google:

- Title 50–60 karakter, keyword di 25–30 karakter pertama, 580–600 piksel, dan 920 piksel untuk description berasal dari pengukuran tool dan lebar tampilan.
- Meta description 140–160 karakter adalah target tampilan, bukan aturan mesin.
- Slug 2–5 kata, 3–7 support keyword, 4–8 H2, 3–6 internal link, 2–4 frasa per 700 kata, dan jarak satu paragraf adalah keputusan kerja di dokumen ini.
- FAQ 4–6 pertanyaan dengan jawaban 40–60 kata, paragraf 2–4 kalimat, lebar gambar 1.600/2.400 px, dan batas ukuran 200/100 KB juga keputusan kerja, bukan angka dari Google.
- Density di atas 2,5% sebagai alarm juga heuristik, bukan ambang resmi.
- Angka 8–12 karakter untuk brand di title, 10–15 karakter untuk suffix plugin, dan 4 minggu untuk mengukur kanibalisasi adalah perkiraan kerja.

Yang resmi dari Google adalah klaim kualitatifnya: title bisa dipotong, meta description sering diganti, keyword di URL berpengaruh sangat kecil, density bukan sinyal, tidak ada panjang isi minimum, dan urutan heading tidak menentukan ranking.

Core Web Vitals memakai ambang resmi: LCP 2,5 detik, INP 200 milidetik, CLS 0,1, diukur pada ponsel.
